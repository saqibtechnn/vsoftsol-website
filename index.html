VSoftSol Syslog Manager

Every log from every device — collected, parsed, and searchable.

One Windows Service. No Elasticsearch, no Java, no Docker, no message broker.

From install to first message, fast

Install

Run the signed MSI, then walk through a five-step first-run wizard that sets up your admin account and HTTPS certificate.

Point your devices at it

Search, alert, report

Everything you need to collect, watch, and report on your logs

Universal syslog collection

UDP, TCP, and TLS syslog listeners, plus SNMP v1/v2c trap intake and an authenticated Windows Event Log forwarder endpoint.

17 vendor parser packs, plus your own

Popular firewalls, switches, and servers ship parsed out of the box; the Pattern Tester lets you build and save GROK/regex extractors against a real sample message.

A real search language

Field filters, quoted phrases, boolean operators, ranges, and wildcards — compiled to parameterised SQL, never string-built.

Rules & alerts

Per-message rules with retried actions (email, webhook, syslog forward, and more), plus aggregation and device-silence alerts with acknowledge/resolve so a spike doesn’t spam you.

Live dashboards

A generic widget framework — any data source, any aggregation, any visualisation — with four shipped defaults including Network Overview.

Scheduled PDF/CSV reports

Build a report once, run it on demand or schedule it, and have it emailed — including canned compliance templates such as a 90-day PCI-DSS report.

Hot / warm / cold retention

Tiered storage with compressed, SHA-256-verified archives and one-click restore — with a disk-usage projection shown before you save a policy.

Roles, MFA & audit trail

Four roles with per-user visibility scope, optional TOTP MFA, Argon2id password hashing, and a hash-chained audit log so nothing quietly disappears.

Config bundles

Export and import rules, streams, devices, users, dashboards, reports, and vendor parser packs as one signed, portable file.

Self-monitoring

The collector watches its own queue depth, dropped messages, disk space, and archive integrity — and alerts you when something needs attention.

Opt-in signed updates

Off by default. When enabled, it checks for a new release, downloads it, and verifies its signature and hash — you always run the installer yourself.

Runs as a Windows Service

Installs once under a dedicated least-privilege account and keeps collecting through reboots, logons, and logoffs — managed from a self-hosted HTTPS dashboard.

FAQ

Frequently asked questions

What are the system requirements?

Syslog Manager runs on Windows Server 2019 or later, or Windows 10 / 11 (64-bit), and needs the ASP.NET Core 8 Runtime (Hosting Bundle) installed first. vSoft-Network-Backup runs on Windows 10 / 11 (64-bit). Run both installers as Administrator.

Do the products need an internet connection?

No. Both run entirely on your own network. Syslog Manager has one optional feature that uses the internet — an update checker that is off by default and only offers releases whose cryptographic signature verifies.

How do I upgrade to a new version?

Download the latest installer and run it as Administrator over your existing install — no need to uninstall first. Your data, settings, and certificates are preserved. See the upgrade guide for details.

How can I verify a download?

Each release lists its SHA-256 checksum on the Updates page. On Windows, run certutil -hashfile <file> SHA256 and compare the result.

Which devices does Syslog Manager understand?

It stores every message it receives, from any device. 17 built-in packs parse Cisco IOS/IOS-XE and ASA, Fortinet, Palo Alto, Juniper, MikroTik, Ubiquiti, Check Point, Sophos, SonicWall, pfSense/OPNsense, Aruba, Huawei, VMware ESXi, and Linux — and the Pattern Tester lets you add your own.
