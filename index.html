vSoft-Network-Backup

A reliable network configuration backup and recovery solution for Cisco routers and switches.

⬇ Download for Windows See features
v2.9.6 Build 012 (Beta) · 25.4 MB · Windows 10 / 11 (64-bit)

vSoft-Network-Backup is a reliable network configuration backup and recovery solution designed for Cisco routers and switches. It automatically collects, stores, and organizes device configurations, helping network teams protect critical settings, reduce manual effort, and recover quickly from configuration loss or device replacement.

With built-in SFTP server capability, vSoft-Network-Backup also provides a secure central location for transferring and managing backup files. Whether you manage a small office network or a large multi-site environment, it helps keep network configurations protected, accessible, and ready when needed.

Beyond individual device backups, a one-click Full System Backup can snapshot the entire install — devices, credentials, schedules, and settings — so the tool itself can be restored in minutes if something ever goes wrong on the server it runs on.

Everything you need to protect your network configs

Scheduled config backups

Set daily, weekly, or custom schedules per device and let vSoft-Network-Backup pull configs automatically — no manual exports.

Full System Backup & Restore

One-click, same-machine disaster-recovery snapshot of the whole install — devices, credentials, schedules, and settings — restorable in a few clicks if something goes wrong.

Built-in SFTP server

A secure, central location for devices or scripts to push backup files to, alongside the standard SSH pull workflow.

Encrypted credential vault

Device credentials are protected with Windows DPAPI, never stored in plain text and never shown back in the UI.

Local HTTPS dashboard

Manage devices, schedules, and backup history from a self-hosted web UI that only your network can reach.

MFA, RADIUS & TACACS+

Admin login supports TOTP-based multi-factor authentication, and can defer to your existing RADIUS or TACACS+ infrastructure.

SIEM export

Forward security-relevant audit events to your syslog/CEF-speaking SIEM — nothing extra to configure beyond a destination.

SSH host-key verification

New devices require explicit host-key approval, protecting you from silent man-in-the-middle swaps.

Runs as a Windows Service

Installs once and keeps running in the background — through reboots, logons, and logoffs.

Version history & diff view

Every backup is kept and diffable against the previous run, so config drift is easy to spot.

VSoftSol Syslog Manager

On-premises syslog collection, parsing, alerting, dashboards, and reporting — one Windows Service, no external runtime dependencies.

⬇ Download for Windows See features
v1.1.1 · 11.8 MB · Windows 10 / 11 (64-bit) · Run installer as Administrator

VSoftSol Syslog Manager collects UDP, TCP, TLS, SNMP trap, and Windows Event Log traffic from every device on your network, parses it with 17 built-in vendor packs — Cisco, Juniper, Fortinet, pfSense/OPNsense, Aruba, and more — or your own custom extractors, and keeps every message exactly as it arrived, whether it parsed cleanly or not. Search it, route it into rules and alerts, put it on live dashboards, and schedule PDF/CSV reports — all from one self-hosted HTTPS web console.

Access control is built in from day one: four roles (Administrator, Operator, Read-Only, Auditor), per-user stream and device scoping, optional TOTP multi-factor on every admin login, and a tamper-evident, hash-chained audit log covering every sign-in, config change, and export.

Nothing about it needs the internet to run — it installs as a single Windows Service bound to your own network. The one exception is entirely opt-in: an off-by-default update checker that only ever downloads a release once its cryptographic signature has verified.

Everything you need to collect, watch, and report on your logs

Universal syslog collection

UDP, TCP, and TLS syslog listeners, plus SNMP trap and Windows Event Log intake — every message stored byte-for-byte, even from vendors with no built-in parser.

17 vendor parser packs, plus your own

Cisco, Juniper, Fortinet, pfSense/OPNsense, Aruba, and more ship parsed out of the box; the built-in Pattern Tester lets you build and save GROK/regex extractors for anything else against a real sample message.

Rules, alerts & live dashboards

Route messages into streams, fire actions — email, webhook, syslog forward, script, ODBC — on match, and get notified the moment a threshold breaches.

Scheduled PDF/CSV reports

Build a report once, schedule it daily, weekly, or monthly, and have it emailed automatically — including compliance-ready canned templates.

Hot / warm / cold retention

Configurable tiering with compressed, integrity-verified cold archives and one-click restore, so you keep years of history without keeping years of disk.

Role-based access + TOTP MFA

Four built-in roles with per-user stream and device-group scoping, and optional TOTP two-factor on every admin login.

Tamper-evident audit log

Every login, configuration change, and export is written to a hash-chained audit trail — nothing quietly disappears from the record.

Config bundles

Export and import rules, streams, devices, users, dashboards, reports, and vendor parser packs as one signed, portable file.

Self-monitoring & self-update

The collector watches its own queue depth, disk space, and archive integrity and alerts on trouble; an optional, off-by-default checker can find, download, and verify a new signed release for you.

Runs as a Windows Service

Installs once and keeps collecting through reboots, logons, and logoffs, managed entirely from a self-hosted HTTPS dashboard your network alone can reach.
