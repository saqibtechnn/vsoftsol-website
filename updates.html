Install asAdministrator (right-click the MSI → Run as administrator, or run it from an elevated prompt).

What’s new

  • Update checks (opt-in, off by default). Settings → Updates can periodically check for a newer release, download it, and verify its cryptographic signature and hash. Nothing installs itself — you download the verified installer and run it, exactly as described below. A release that fails verification is never offered and is recorded in the audit log.
  • Fixed: exporting a config bundle. Settings → Config bundles → Export returned an error page. It now downloads the signed bundle.
  • Fixed: “Run now” report downloads and the first-run “Waiting for messages” page. Both hit the same underlying error; on-demand PDF/CSV reports download again, and the first-run page auto-advances to the dashboard once your first message arrives.
  • Fixed: the installer’s .NET Runtime check. Earlier installers reported the ASP.NET Core Hosting Bundle as missing on every machine, even when it was installed. This build passes the check correctly.
  • The product’s internal version number now matches its release version.

How to update an existing install

  1. Download the installer above and, if you like, compare its SHA-256 with the value shown (certutil -hashfile VSoftSolSyslogManagerSetup-1.1.1.msi SHA256).
  2. Run it as Administrator directly over your existing install — there is no need to uninstall first.
  3. The service is stopped and restarted automatically. Expect a brief gap in collection (seconds to low tens of seconds); schedule the upgrade outside your busiest period if that matters, since a long gap can drop UDP datagrams.

Your database (events, streams, rules, alerts, dashboards, reports, users, audit log), data directory, HTTPS certificate, and listener-port overrides are all preserved.

Tip: before any upgrade you can take an extra safety copy with Settings → Config bundles → Export (rules, streams, devices, users, dashboards, reports, parser packs), or copy the whole data directory while the service is stopped.

Earlier VSoftSol Syslog Manager releases

v1.1.0

September 15, 2026 · superseded by v1.1.1 (its installer has the .NET Runtime check bug fixed in v1.1.1)
  • TOTP MFA enforced at sign-in. Enabling MFA on an account now actually changes what signing in requires — a code or unused recovery code, with its own rate limit.
  • Live UDP/TCP listener port changes. Change either port in Settings → Listeners and it applies immediately, with no restart; a mistyped or already-used port is rejected and the previous port keeps running.
  • Saved extractors are applied at ingest, including for devices with no built-in vendor pack.
  • Reports say when a query failed instead of looking like an empty report.
  • Exact “would have fired” alert preview for every alert type, and a correct warning when a very busy window’s count is a lower bound.
  • Every stored message now links back to the listener that received it; the data-directory relocation procedure is documented.

v1.0.0

September 12, 2026 · first general release
  • Universal syslog collection (RFC 3164/5424) plus TLS syslog, SNMP traps, and a Windows Event Log forwarder endpoint — nothing dropped for coming from an unrecognised vendor.
  • 17 vendor parser packs and a Pattern Tester for your own.
  • Search language, rules and alerts, dashboards, and scheduled PDF/CSV reports including compliance templates.
  • Hot/warm/cold retention with verified archives, role-based access, TOTP MFA enrollment, audit log, and signed configuration bundles.
  • Signed MSI installer with a five-step first-run wizard, designed to get you to your first message in under ten minutes.
